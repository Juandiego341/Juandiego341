## 📌 Highlight Projects

### 🏢 [WMS — Florida Importaciones](https://florida-importaciones.vercel.app/)
> Logistics dispatch management system built for a real company — live in production.

- **100+ orders processed daily** by a team of **30+ active users**
- State machine per dispatch phase: *separated → marked → packaged* with real-time chronometers
- Role-based access control with 5 roles (ADMIN, WORKER, SALES LEADER, SELLER, WAREHOUSE ADMIN)
- Real-time updates via **Supabase Realtime** (no polling)
- Signed upload to **Cloudinary** directly from the browser — solving Vercel's 4.5MB serverless limit
- Returns & warranty module with approval flow and automatic monthly cleanup via Vercel Cron Jobs
- **90 automated tests** with Vitest + Supertest (unit + integration)
- **Stack:** Node.js · Express 5 · PostgreSQL · Prisma · Supabase · JWT · Zod · Cloudinary · React 19 · Vercel

---

### 🧾 [Smart Data Syncro](https://github.com/Juandiego341/Smart_data_syncro)
> Desktop ERP that eliminated 100% of manual billing and inventory tracking for a real business.

- Integrated with **Facturatech** for electronic invoicing compliant with Colombia's DIAN
- Offline-first local database with SQLite — works without internet connection
- Built for non-technical users with zero onboarding required
- 2+ years of active development and real-world daily usage
- **Stack:** Python · Tkinter · SQLite
